# ⚔️ RenFest Raid

Live day planner for the crew at the Texas Renaissance Festival.

**Open it:** https://capsail.github.io/renfest-raid/

**Cap:** to update everyone's phones, edit
[`live.txt` on the gh-pages branch](https://github.com/CapSail/renfest-raid/edit/gh-pages/live.txt)
and commit. Phones pick it up in about a minute.
